# GDCE Trade Service — Bruno API Client Demo Guide

Using Bruno (or Postman) to demo your backend service is an excellent way to show off your technical architecture and API contracts.

### Global Bruno Configuration
* **Service Base URL:** `http://localhost:8004` (FastAPI Trade Service Gateway)
* **Headers:** `Content-Type: application/json`

---

## 1. Bruno Demo Storyboard (6 Requests)

### Request 1: The Happy Path (Summary Intent)
* **Endpoint:** `POST http://localhost:8004/query`
* **Request Body (JSON):**
  ```json
  {
    "question": "How much did Cambodia trade with Vietnam in 2025?"
  }
  ```
* **Response Highlight (What to expand in Bruno):**
  * Expand `summary` $\rightarrow$ shows `total_trade_value`.
  * Expand `message` $\rightarrow$ shows the clean conversational NLG paragraph generated by Gemini.
  * Note how the system returns a status code of `200 OK`.

---

### Request 2: Limit & Sort Aggregations (Ranking Intent)
* **Endpoint:** `POST http://localhost:8004/query`
* **Request Body (JSON):**
  ```json
  {
    "question": "What were the top 5 export partner countries in 2025?"
  }
  ```
* **Response Highlight (What to expand in Bruno):**
  * Expand `visualization` $\rightarrow$ point out `"type": "bar"` (confirming the visualizer mapped it correctly) and `"sort_col": "VALUE_USD"`.
  * Expand `records` $\rightarrow$ show that exactly 5 records are returned, ordered from highest to lowest.

---

### Request 3: Time-Series Timeline (Trend Intent)
* **Endpoint:** `POST http://localhost:8004/query`
* **Request Body (JSON):**
  ```json
  {
    "question": "Show the monthly export trend for Vietnam over the last 3 years"
  }
  ```
* **Response Highlight (What to expand in Bruno):**
  * Expand `query_params` $\rightarrow$ point out that relative time `"last 3 years"` was resolved by Gemini into `start_period` (e.g. `2023-01`) and `end_period` (e.g. `2025-12`) with `frequency: "M"`.
  * Expand `visualization` $\rightarrow$ point out `"type": "line"`.

---

### Request 4: Side-by-Side Comparison
* **Endpoint:** `POST http://localhost:8004/query`
* **Request Body (JSON):**
  ```json
  {
    "question": "Compare exports to China vs Thailand in 2025"
  }
  ```
* **Response Highlight (What to expand in Bruno):**
  * Expand `query_params` $\rightarrow$ point out `partner_countries` list is populated with `["CN", "TH"]` and the intent is recognized as `"comparison"`.
  * Expand `message` $\rightarrow$ show the comparative paragraph comparing China's vs Thailand's values.

---

### Request 5: Net Trade Balance (Calculated Logic Flow)
* **Endpoint:** `POST http://localhost:8004/query`
* **Request Body (JSON):**
  ```json
  {
    "question": "What is Cambodia's trade balance with Japan?"
  }
  ```
* **Response Highlight (What to expand in Bruno):**
  * Expand `query_params` $\rightarrow$ point out that the `trade_direction` (FLOW filter) is omitted/null. (This is because the backend needs both EX and IM data to compute the balance).
  * Expand `records` $\rightarrow$ show rows for both `EXPORT` and `IMPORT`.
  * Expand `message` $\rightarrow$ highlight the text containing the net balance calculation and surplus/deficit verdict.

---

### Request 6: Parameter Extraction Debugging
*Showcases how developer/debugging endpoints work without calling the live database.*
* **Endpoint:** `POST http://localhost:8004/extract-params`
* **Request Body (JSON):**
  ```json
  {
    "question": "Show exports to Vietnam last year in Khmer Riel"
  }
  ```
* **Response Highlight (What to expand in Bruno):**
  * Point out the returned **raw parameters** extracted by Gemini.
  * Highlight that `metrics` contains `VALUE_USD` because the query orchestrator automatically substituted the unsupported `VALUE_KHR` parameter to protect the query.

## 2. Direct DAL Proxy Query Demo (Bonus)

# GDCE Trade Service — Presentation Demo Video Guide

Recording a pre-recorded demo video is a best practice for presentation day. It guarantees that slow LLM network API latencies do not delay your speech, and it prevents unexpected live database outages from crashing your demo.

Below is a storyboarded guide of **6 distinct demo cases** that showcase the full range of the Trade Query Service's capabilities, from simple questions to complex logical overrides.

---

## Storyboard Flow

```
[Intro: UI Interface] ──> [Case 1: Happy Path Summary] ──> [Case 2: Top N Ranking]
                                                                │
                                                                ▼
[Conclusion & Suggestions] <── [Case 5: Error Resiliency] <── [Case 4: Trade Balance] <── [Case 3: Timeline Trend]
```

---

## Demo Case 1: The Happy Path (Summary Intent)
*Showcases standard natural language mapping, structured database lookup, and clean visualizations.*

* **User Input to Type:** 
  > *"How much did Cambodia trade with Vietnam in 2025?"*
* **What to Show on Screen:**
  * The typing animation.
  * The loading spinner (approx. 2-3 seconds).
  * The final output card showing:
    1. A single summary statistic card (KPI value in USD).
    2. A clean data table showing the transaction totals.
    3. The natural language text paragraph explaining the trade total.
* **Speaker Voice-Over / Script:**
  * *"First, let's look at the basic query flow. We ask about Cambodia's trade with Vietnam in 2025. The system automatically classifies this as a `summary` intent, translates the year '2025' and 'Vietnam' to its ISO-2 code 'VN', queries the DAL, and returns a natural language summary alongside the raw statistics."*

---

## Demo Case 2: The Top N List (Ranking Intent)
*Showcases limit aggregation, sorting parameters, and horizontal bar charts.*

## Demo Case 6: Resiliency, Overrides & Fallbacks (The "Trust Builder")
*Showcases how the system handles invalid entries, currency overrides, and LLM correction loops.*

* **User Input to Type:**
  > *"Show exports to Vietnam last year in Khmer Riel"*
* **What to Show on Screen:**
  * Show the text response output.
  * Focus on the NLG summary text which notes: *"Riel values are unavailable in our dataset. Statistics are provided in USD."*
* **Speaker Voice-Over / Script:**
  * *"Finally, we demonstrate system resilience. The user asked for values in Cambodian Riel, which our database does not record. Instead of throwing a database connection error, our orchestration layer intercepts the request, substitutes KHR with USD, executes the query safely, and warns the user in the text summary. This guarantees a smooth user experience even with unsupported request parameters."*

## 💡 Practical Recording Tips

1. **Use Fake Wait Times (Speed it up):** Don't make your audience wait 3 seconds for every query to load. Record the typing and loading screen, then edit/cut out the spinner frame so the response appears instantly.
2. **Highlight Elements with Zoom:** During editing, zoom in slightly on the specific element you are talking about (e.g., zoom in on the horizontal bar chart when explaining Stage 5b Normalization).
3. **Capture the Suggestions:** End your video by clicking on one of the **3 follow-up suggestion chips** (e.g., *"Show the monthly trend for Vietnam"*) to show how the conversational flow continues dynamically.
